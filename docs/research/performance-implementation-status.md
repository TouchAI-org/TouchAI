## 新基线的职责边界

沿用 main 的透明原生宿主、共用卡片/弹层几何所有者、同一主 WebView 弹层、原生可见性确认、可取消挂载等待、WAAPI 动画交接和注入式拖动。手动拖动允许卡片出屏，只有弹层受可见工作区约束；保留 `border-0`。

动效使用主线共享策略的 1.2/1/0.65 速度、OS reduction、压力恢复和 native visibility。`useMotion` 仅暴露已有可见性状态供展示计时器使用，不增加采样器。旧唤醒、原生 popup、窗口状态并行探针和 motion.css 修复不再是本 PR 的净增量；popup TTL 与冷/热原生 popup 埋点随旧架构退出。

滚动保留主线单一 rAF 测量、contentResize 和固定视口合约，接入 virtua/keepMounted 导航。移除逐帧贴底循环、额外跟随状态、布局宽限定时器、自定义消息高度估算及重复测试；减少动态效果回归验证主线样式。

## 本轮整合修正

- 布局引发的 scroll 不再误判为用户离底；保留明确用户输入停止跟随和导航的行为。
- 历史搜索输入时立即废弃旧请求，取消防抖会结束被替代的 Promise，关闭弹层后不启动查询。
- 去掉 widget UI 的 callId 回退，保持投影层同步 retarget 的单一契约。
- 附件去重回到 materialize owner，保留逐源读取、失败日志和跳过坏文件的语义。
- 设置预热支持提升已排队项优先级，卸载取消队列；滚动位置等异步分区 resolve 后恢复。
- 删除未经收益测量的 canvas/WebP 二次解码管线，仅保留原图 lazy/async 加载与 GIF 来源。
- snapshot 仅保留已批准的生成列、五个索引和必要元数据增量；移除缩进噪声，journal 与 main 相同。
