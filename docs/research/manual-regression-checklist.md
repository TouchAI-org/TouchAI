## 环境

- 使用本 worktree 的隔离数据副本。独立 dev identifier 为 `org.touch-ai.app.perfdev`；前端端口与 Tauri devUrl 一致，不占用正在使用的实例。本页不表示实例正在运行。
- 保留复现数据；需要空库时创建新目录，不删除正式库或已有副本。
- 预置 70 条合成消息与真实重消息会话（代码、图片、工具、widget）；合成场景不能代替后者。
- 保持用户正常 DPI/缩放。卡片位于透明原生宿主内，调整卡片走现有几何 owner，不通过 setWindowSize 改宿主模拟。
- 可读 `window.__TOUCHAI_PERF__.getSamples()`（开发默认开启，生产默认关闭）；采样不含会话内容，也不替代 release 性能比较。

## 核心场景

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| A1 | 冷启动并立即发消息 | 外壳先可用，任务等待能力就绪后执行 |
| A2 | 能力准备中对同一会话连续重新生成 | 只启动一个任务，仍可按会话取消 |
| A3 | 打开设置及添加 provider 对话框 | 不重复初始化后台工具，异步内容正常出现 |
| A4 | 切换设置分区、返回长分区，再关闭窗口 | 内容就绪后恢复各自滚动位置，关闭后不继续启动排队预热 |
| B1 | 输出长文本、公式和 >200 行代码 | 内容完整，数学边界正确；流式长代码用纯文本，结束恢复增强渲染 |
| B2 | 收起 reasoning，隐藏原生窗口再唤醒 | 卸载完整 Markdown；隐藏期暂停展示计时器，返回时耗时正确 |
| C1 | 打开 70 条消息和 11/12 条临界会话 | 初始贴底，≥12 条窗口化且挂载有界，<12 条直接渲染 |
| C2 | 输出中手动上滚，再跳到底部 | 离底保持阅读位置，主动回到底部恢复跟随 |
| C3 | 远距离切换定位项，再重复点同一项 | 从首次到达起稳定，不反复校正，提问/回答区间高亮正确 |
| C4 | 定位后用滚轮、触摸或 PageDown 阅读 | 解除导航锚定，不拉回原位置 |
| C5 | 打开含图片、代码、widget 的真实重消息 | 异步布局不导致离底漂移或持续 ResizeObserver 循环；图片后加载单独记录 |
| C6 | 系统/自动 reduction、三档速度下重复 C3/C4，再关闭对话框 | 定位、关闭完成和清理正常，速度来自共享策略 |
| C7 | 跨虚拟消息选择文本 | 记录卸载对选区的影响；此项尚无完成结论 |
| D1 | 大输出 Bash，并覆盖首尾边界中文/ASCII 混合 | 流式可见，终态有界输出带正确截断标记且保持字符顺序 |
| D2 | 搜索内置工具/MCP 日志并展开详情 | 摘要先加载，详情按需读；搜索匹配工具名/摘要/输入前缀 |
| D3 | 生成 >2000 字符 widget，暂停增量，再完成/取消 | 已有 HTML 不清空，尾沿发布最新草稿，旧任务不覆盖终态 |
| D4 | 切换含定时器/listener/observer 的 widget | 已拦截资源停止；不宣称任意生成脚本资源均被隔离 |
| D5 | 审批工具、取消 WebFetch、回答/跳过提问 | 状态即时有序，取消后不写回，空问题不挂住队列 |
| E1 | 历史弹层快速输入，再关闭/重开 | 150ms 停顿后查询，旧响应不覆盖新词，关闭后不启动旧查询 |
| E2 | 快搜翻页期间改变查询 | 旧代结果不写回新列表 |
| E3 | 历史搜索工具输出中的词 | 保留子串语义 |
| E4 | 同源图片/GIF 多次附加，夹带坏文件 | 保留原始来源，批次内复用读取；坏文件记录并跳过，健康附件继续 |
| F1 | 手动拖卡片越过屏幕边缘，再开历史/模型弹层 | 卡片可出屏且不自动缩窗，弹层留在可见工作区 |
| F2 | 快速显示/隐藏、切换会话并触发内容动画 | 透明宿主稳定，native visibility、挂载取消和 WAAPI 交接正常，无会话外圈 |

## 自动化与人工边界

- `conversation-scroll.e2e.js` 保留六项合成长文本场景与 2px 逐帧断言，用主线 resetSearchSurface。新 HEAD 的 CI 检查 Windows 原生程序和真实 Markdown。
- 本轮 headless Edge 探针在普通、OS reduction、共享策略 reduction 下四次跳转均为 0px，PageDown 解除锚定。MessageItem 使用合成文本，出现 ResizeObserver 延迟通知，不覆盖 C5/C7 或原生生命周期。
- 故障注入覆盖事务回滚后完成/取消/继续写入、并发启动、widget 尾沿/终态、snapshot 一致性和 Bash UTF-8 边界，不操作真实用户库。
- 旧人工验收和旧 CI 绿灯仅为历史记录。本轮真实会话、显示条件和完整 PR 人工验收仍待完成。
- release 冷/热 P50/P95、稳态内存与 DOM/renderer 比较按原约定延期；5% 回归预算尚未验证。

## 数据库升级

关闭写入方或通过 SQLite 备份取得一致副本，放到非系统盘隔离目录。保留原副本用于比较/恢复，不对正式库操作。

v1.2.2（0000–0003）升级应依次执行已发布的 0004 和新增的 `0005_performance_query_indexes`；v1.3.0-beta.1（已登记 0004）只执行 0005，不重跑 0004。两条路径均应保留会话、正文、工具、附件和用量数据，历史搜索继续可用。

用户已要求将本 PR 的数据库增量独立迁移，0004 SQL 和 snapshot 保持与 beta 发布版一致。新增索引会扫描存量数据，实际耗时、锁等待和 WAL 增长待真实副本验证；临时 beta 升级演练、10,004 条旧消息夹具和 snapshot 零增量检查不能代替该验收。中途失败应整体回滚，重启可重试。升级后的库不能交给旧 beta 直接打开；回退时使用升级前的一致备份，不重置正式库。
