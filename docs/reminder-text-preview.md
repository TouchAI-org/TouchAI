# 通知正文预览

通知正文是纯文本，最多 220 个 UTF-16 单元（包含省略号），截断不会切开代理对。

- 助手回复、审批原因和待回答问题：使用已有 Markdown 解析器提取文字，不改写或二次解析输入。
- 完成通知：取最近一条非空助手回复的前四个非空文本段；标题、列表和段落使用固定的中英文分隔符。
- Markdown 链接保留标签文字，图片保留替代文字；表格按行输出，单元格使用列表分隔符。
- 行内代码和代码块保留内容。正文中的特殊路径、glob 和诊断符号应使用代码标记包裹。
- 转义字符遵循标准 Markdown 语义。例如 `\*\*文字\*\*` 显示为 `**文字**`，不会再次解释成加粗格式。
- 原始 HTML 作为字面文本保留，不执行、不猜测标签含义，也不进行跨段标签配对。
- 错误和命令：仅折叠空白、限制长度，保留路径、Markdown 标记、尖括号和引号。
- 审批命令最多 160 个 UTF-16 单元；移除包裹整个命令的三反引号或三波浪号代码围栏，并为命令预留正文空间。
- Markdown 最多扫描输入的前 4096 个 UTF-16 单元。解析异常时退回这部分输入的原文预览。

这些规则由 `apps/desktop/tests/utils/reminderText.test.ts` 和任务中心通知测试覆盖。
